# CTET / UPTET Mock Tests

Hindi-medium online practice tests for CTET and UPTET. These are independent practice materials and are not official exam papers.

## UPTET Paper II — Sanskrit Language II
- [UPTET 2026 Paper 2 Mock Test 6 — Hindi + Sanskrit](uptet-paper-2-mock-6.html)
- 150 MCQs, 150 marks, 150 minutes; Hindi Language I, Sanskrit Language II, Child Development & Pedagogy, Mathematics and Science.
- Question set was checked against existing Mock 2–5 pages to avoid reusing the same question wording where possible. Original-style practice questions, not a verbatim reproduction of a past paper.
